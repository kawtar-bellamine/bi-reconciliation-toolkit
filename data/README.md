# Data

`raw/onlineretail.rda` is the *Online Retail* data set: every line of every invoice of a UK-based online
retailer of gift items, many of whose customers are wholesalers, from 1 December 2010 to 9 December 2011
(541,909 lines, 8 columns).

* Original source: Daqing Chen, Sai Liang Sain and Kun Guo, *Data mining for the online retail industry: A case
  study of RFM model-based customer segmentation using data mining*, Journal of Database Marketing and Customer
  Strategy Management, 19(3), 2012. Published in the UCI Machine Learning Repository.
* This copy comes from the R package [`onlineretail`](https://github.com/allanvc/onlineretail) (file
  `data/onlineretail.rda`), which redistributes it under CC0 with the donor's permission.
* SHA-256: `d686c7ec387fdc64fde3a5b6f1c31d43751735f4053f34c92e677beacf5e0664` (checked when loading).

Amounts are in pounds sterling. The file is used as delivered: every correction happens in the pipeline and is
reported, so the raw file stays the reference that the report is reconciled against.
